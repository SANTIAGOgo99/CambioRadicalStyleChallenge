# Audio del primer nivel

- `audio/music/salon_loop.wav`: composición instrumental original generada mediante síntesis;
  bucle de 19,2 segundos, marimba suave, bajo y percusión ligera.
- `audio/effects/`: seis efectos originales sintetizados para botones, herramientas y resultados.
- `audio/voice/`: ocho clips de diálogo sintetizados localmente mediante las voces españolas
  de Windows, Microsoft Sabina (Sofía) y Microsoft Raúl (Ezequiel).
- Textos editables en `data/dialogue.json`; no hay grabaciones de personas reales.
- No se usan música, voces ni efectos extraídos de los PDF o descargados de internet.
